# Pakistan transaction-volume demo

Open the HTML directly in a browser. Leaflet 1.9.4, the geoBoundaries 2019 Pakistan district polygons, and searchable GeoNames populated places are embedded. Counts are synthetic district totals. There are no urban-footprint overlays.

Data sources: https://www.geoboundaries.org/api/current/gbOpen/PAK/ADM2/ (public domain) and https://download.geonames.org/export/dump/PK.zip (CC BY 4.0).
